Cluster 4

Marine Spatial Data Infrastructure

How to understand MSDI as an institutional system, record minimum metadata, agree interoperable exchange between agencies, and establish stewardship arrangements for Seychelles marine data.

Last reviewed November 2026

Treat infrastructure as an institutional system

MSDI includes governance, standards, people, data and services. A portal can improve discovery while leaving authority, update responsibilities and funding unresolved. Start with the Seychelles institutions that collect, maintain, approve and use the evidence. Distinguish technical hosting from legal control and stewardship.

Data sovereignty requires explicit authority over access and use under applicable law and institutional arrangements. An overseas server or an imported dataset does not by itself establish the degree of national control. Examine contracts, licences, decision rights, access dependencies and exit options.

Record minimum metadata

Metadata should identify a dataset, custodian, version, spatial and temporal extent, reference systems, methods, quality, licence, sensitivity, access route and update schedule. Include a usable contact and distinguish a catalogue page from a download endpoint.

Use a persistent identifier when available. Record lineage from original observations through clipping, reprojection and classification. A metadata record for a controlled dataset can remain publicly discoverable without exposing the data itself. Do not publish sensitive vessel coordinates merely to demonstrate openness.

Agree interoperable exchange

Interoperability covers shared meanings as well as compatible file formats. Agree units, controlled vocabularies, date conventions, geometry types and identifiers before merging inter-agency layers. Validate geometry and CRS at exchange boundaries.

WMS provides rendered maps, while WFS provides access to vector features subject to service configuration and permissions. A working map image does not prove that downloadable features or redistribution rights exist. Keep licences attached to exported data and document API limits, authentication and maintenance responsibility.

Establish a stewardship agreement

For a Seychelles marine data partnership, name the custodian, access approver, technical maintainer and escalation contact. Set an update cycle, archival procedure, backup location and recurring budget. Define how partners correct errors and how the national institution retrieves its records if a project or hosting agreement ends.

Classify access deliberately: public, registered, controlled or withheld with justification. Use proportionate controls and document the authority for each restriction. Open access and national governance can reinforce one another when responsibilities and reuse conditions remain explicit.

Practice

Prepare a one-page agreement for sharing a Seychelles habitat layer between a survey team and a planning authority. Specify the authoritative version, permitted uses, acknowledgement, update route and treatment of sensitive fields.
