Cluster 1

Hydrospatial Foundations

How to define a spatial question, handle coordinate reference systems and datums, and apply a reproducible workflow before choosing or combining marine data products.

Last reviewed November 2026

Define the spatial question

A Seychelles marine dataset can support one decision and fail another. A regional grid may describe the Seychelles Bank while missing the detail needed for a harbour approach. Define the decision, spatial extent, minimum feature size and acceptable uncertainty before choosing a product. Include the outer islands when a national analysis requires them.

Hydrospatial work joins observations to the institutions that maintain and use them. Treat local knowledge and national survey holdings as evidence alongside global products. Record where imported products leave gaps rather than interpreting gaps as absent habitats or activity.

Separate position from height

A coordinate reference system describes how coordinates relate to Earth. Record the datum, coordinate order, units and projection. Geographic coordinates usually require longitude and latitude; a projected layer uses linear units. Confirm the actual CRS from metadata before transforming a layer. Assigning a CRS label does not transform coordinates.

GNSS commonly reports ellipsoidal height. An orthometric height uses a gravity-related reference, often a geoid model. The familiar relationship between ellipsoidal height, orthometric height and geoid undulation depends on compatible conventions. Do not use a global geoid correction as a substitute for a documented local vertical transformation.

Keep depth references explicit

A chart datum provides a reference for charted depths. Mean sea level, a tidal datum and the satellite reference ellipsoid are not interchangeable. A bathymetric grid may combine sources with different vertical references or incompletely known origins. Check product documentation and retain unresolved differences in the uncertainty statement.

For a Mahé coastal assessment, list each elevation source, reference surface, tidal observation period and transformation. State whether depths increase downward and elevations increase upward. Never subtract two rasters solely because they appear aligned on screen.

Apply a reproducible workflow

  1. State the intended use and decision scale.
  2. Record source version, horizontal CRS and vertical reference.
  3. Check units, axis order, land masks and nodata conventions.
  4. Transform using a documented operation and retain the originals.
  5. Inspect known positions and quantify remaining misalignment.
  6. Report what the evidence can support and what requires a local survey.
Practice

Compare a GEBCO extract with a terrestrial elevation product around Mahé. Write a short note identifying which cells represent seabed information, which represent land elevations and why the combined surface cannot establish safe navigable depth.
